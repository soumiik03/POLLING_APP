# Polling App

A full-stack polling platform where users can create polls, share them using a public link, and collect responses.

## Features

- Create polls with multiple questions
- Single option selection questions
- Public shareable poll links
- Anonymous or authenticated responses
- Mandatory and optional questions
- Poll expiry support
- Responsive UI

## Tech Stack

### Frontend
- React
- Vite
- Axios

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
